# Thảm nhiệt đá thạch anh tím

Trang tĩnh một file `index.html` (HTML, CSS, JS thuần) để đưa vào hệ thống tạo landing page.

Thông điệp: giữ ấm, thư giãn, hỗ trợ giảm đau mỏi tạm thời. Không quảng cáo chữa bệnh hoặc thải độc. Công suất, dải nhiệt và chứng nhận để trống cho đến khi nhà cung cấp xác nhận.

Banner đầu trang cao tối thiểu bằng một màn hình (`100dvh`). Ảnh trong `images/` là ảnh giữ chỗ; thay trong CMS sau khi đưa link vào hệ thống.
